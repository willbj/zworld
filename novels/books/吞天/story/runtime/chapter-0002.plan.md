# 第 2 章 memo

## 本章目标
让白邺第一次主动使用吞噬能力吞噬卷轴，获得功法真义与第一块信息拼图

## 关联线索
- H001
- H002

## 当前任务
白邺在崖底尝试吞噬卷轴——从“饥饿本能驱使”到“主动控制吞噬过程”，获得吞天诀第一层运转法门。

## 读者此刻在等什么
1) 读者期待看到金手指落地——吞天诀到底怎么用、有什么效果、代价是什么，第1章只埋了“吃”的暗示，第2章必须兑现一次具体操作。
2) 本章完全兑现这个期待：白邺主动吞噬卷轴，展现吞噬过程的感官细节、能量流转、以及第一次使用后的副作用/限制，让读者看到能力的具体形态而非概念描述。

## 该兑现的 / 暂不掀的
- 该兑现：H002（吞天诀运作方式）→ 白邺通过吞噬卷轴获得功法第一层运转路径，但功法真名、完整来历、代价上限仍不揭示
- 该兑现：mystery-卷轴用途 → 卷轴被吞噬后，白邺脑中浮现功法路径与一段残破记忆画面（老人年轻时在某遗迹获得此物），但画面不完整
- 暂不掀：H001（养父身份与吞天诀关联）→ 卷轴被吞噬后白邺只获得“养父也修炼过此诀”的模糊感应，不点明具体关系
- 暂不掀：mystery-第三人身份 → 本章完全不提第三人，留到第4章左右回收

## 日常/过渡承担什么任务
不适用 - 本章无日常过渡。白邺从崖底起身到完成吞噬的过程是连续的高压状态（饥饿、警惕周围、尝试控制体内力量）。

## 关键抉择过三连问
- 主角本章最关键的一次选择：是否真的把卷轴吃下去——不是咬碎咽了，而是用体内那股奇异力量去“包裹、分解、吸收”卷轴。
  - 为什么这么做？饥饿感从胃底烧到喉咙口，身体在叫嚣着要吞噬一切，理智告诉他卷轴可能是唯一线索，但本能压倒理智——他选择相信身体的直觉。
  - 符合当前利益吗？符合。他重伤刚愈、身处荒山、对功法一无所知，卷轴是他唯一的信息来源，吞噬是获取信息的唯一途径。
  - 符合他的人设吗？完全符合。饥饿是白邺的性格底色，不讲规矩、不按常理行事，面对未知选择“吃下去”而不是“研究一下”正是他的人设体现。
- 对手/配角本章最关键的一次选择：无（本章没有配角登场）。

## 章尾必须发生的改变
1. **信息改变**：白邺获得吞天诀第一层运转路径，知道这套功法需要持续吞噬“蕴含灵性的东西”来推进，且第一次吞噬后会有一段“消化期”（暂时无法再次吞噬）。
2. **物理改变**：卷轴消失，白邺体内多了一条游走的能量流，从丹田位置开始沿着经脉流转。
3. **权力改变**：白邺从“被动承受饥饿”变为“主动感知饥饿——知道饥饿意味着可以吞噬什么”，获得对自身能力的最低限度控制感。

## 本章 hook 账
open:
- [new] 吞天诀第一层后遗症——消化期内吞噬效率下降且饥饿感会成倍反噬（白邺不知道反噬何时来）|| 理由：为下一章制造紧迫感，消化期是白邺的弱点窗口期，为第3章可能出现的敌人埋下伏笔

advance:
- H002 “吞天诀的来历/真名/代价” → 白邺吞噬卷轴后获得功法第一层运转路径，但真名和完整代价仍未揭示（mystery → partial_reveal）
- H001 “身世/养父身份” → 吞噬过程中白邺模糊感应到养父也修炼过此诀（progressing → advanced，但未resolve）

resolve:
- mystery-卷轴的具体用途和来历 → 卷轴被吞噬，其信息内容（功法路径+残破记忆画面）被白邺吸收（open → resolved）

defer:
- mystery-第三人为何离开 → 本章不动，理由：白邺身处崖底，第三人去向不在当前场景内，留到第4章白邺离开崖底后自然触发

## 不要做
1. 不要让白邺吞噬卷轴后立刻战力暴涨——只获得功法路径和一段记忆画面，不获得直接战斗力提升
2. 不要在这个阶段引入新角色/新敌人——白邺独自在崖底完成吞噬，场景封闭，不给第三人或其他势力出场
3. 不要解释功法原理或修炼体系——只通过白邺吞噬时的感官体验（能量在经脉中游走、丹田发热、饥饿感变化）来自然带出规则
4. 不要写白邺在吞噬前犹豫、纠结、自我对话——他的饥饿感压倒一切，动作应该干脆利落
